# CHANGELOG

## 1.0.0

- Initial release of Samsara Bus Bloc extension
- Added `BusBloc` class that extends Bloc with bus integration capabilities
- Added topology support for complex stream processing
- Added `onBusTopic` method for subscribing to bus topics
- Added `onTopology` method for subscribing to topology results
- Added `emitToBus` method for sending messages to bus topics
- Added comprehensive topology builder API
- Added support for multiple stream combiners (combineLatest, zip, merge, withLatestFrom)
- Added type-safe event and state handling
- Added complete test coverage

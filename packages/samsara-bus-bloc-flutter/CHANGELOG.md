# CHANGELOG

## 1.0.0

- Initial release of Samsara Bus Bloc Flutter widgets
- Added `BusBlocProvider` for providing BusBloc instances
- Added `BusBlocBuilder` for building UI from BusBloc state
- Added `BusBlocListener` for listening to BusBloc state changes
- Added `BusBlocConsumer` for combining building and listening
- Added `BusEventBuilder` for building UI with access to recent bus events
- Added `BusEventListener` for listening to both state and bus events
- Added `BusEventConsumer` for comprehensive event-aware widgets
- Added Flutter example demonstrating usage
